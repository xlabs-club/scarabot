## 什么是 Scarabot？

Scarabot（黑武士）是一个专注于**代码清理**的 agent 与 skill 仓库，专啃别人不敢碰的代码库。

盘根错节的祖传模块、谁都不敢删的半死分支、熬过了三次重写的"临时"垫片、披着功能外衣的僵尸代码——Scarabot 一路滚过去，精准识别哪些已死、哪些冗余、哪些是隐患，然后以手术刀般的精度清扫干净。

## 它能做什么

- 🧹 **死代码清理** — 识别无用的导出、不可达分支，以及无处安放的 import。
- 🔁 **冗余消除** — 检测重复逻辑，收敛为单一可信源。
- 🗑️ **陈旧清理** — 追踪废弃路径、僵尸配置，以及本该属于 git 历史而非源码的注释块。
- ⚔️ **安心重构** — 提出结构改进方案，并以可审阅的小步增量逐一落地。
